# Target demo app

React/Vite at loopback :5174, served as built assets in default Compose. A deliberately small synthetic session, handler and worker-job interface makes the catalog effects observable. Hit handler uses GET /probe and never enqueues. Each action has independent pending state, feedback and observation time. Health and jobs poll independently; outages preserve labelled last-known records.

Its /api proxy only permits public target routes, with bounded requests and no private authorization headers. Use the root docker-compose.dev.yml override for hot reload. See [WALKTHROUGH](../../docs/WALKTHROUGH.md) and [QUALITY](../../docs/QUALITY.md).
