# Sealed console

React/Vite operator app at loopback :5173. Default Compose serves built assets through packages/web/server.mjs. Same-origin /api routes reach control and /target routes allow only public target probes. Private target operations and x-sealed headers are blocked by both static and development proxies.

The composer is separate from selected run state. The global active-run banner retains scoped abort across navigation/refresh, including while planning is pending. History, actual events and measured evidence share a deep-linked run identity. Independent cancellable polling preserves labelled stale observations on errors. The planner drawer supports keyboard sizing, controlled following and bounded persisted dimensions.

Fixture replay reads bundled /replay/seals/ assets, so the web container runs by itself after an initial build. TARGET_APP_URL sets the local display link at runtime (default http://localhost:5174); it never configures injection targets. For Vite hot reload use the root docker-compose.dev.yml override.
